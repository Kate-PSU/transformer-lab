# Transformer Lab

Автономный интерактивный тренажёр по статье Vaswani et al. *Attention Is All You Need* для занятий по техническому переводу.

## Содержание

- 6 заданий по терминологии;
- 6 заданий на понимание статьи;
- 6 заданий по переводу и редактированию;
- мгновенная обратная связь;
- итоговый профиль по трём компетенциям;
- сохранение последнего результата в браузере.

Для локального запуска откройте `dist/index.html` в браузере.
